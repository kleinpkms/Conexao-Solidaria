# 🤝 Conexão Solidária

Um projeto web desenvolvido com o objetivo de auxiliar pessoas a compreender seu perfil profissional e identificar ambientes de trabalho mais compatíveis com suas características, com foco em usuários com Transtorno do Espectro Autista (TEA).

## 💻 Sobre o Projeto

O **Conexão Solidária** nasceu da necessidade de combater as dificuldades que muitas pessoas com Transtorno do Espectro Autista (TEA) enfrentam no processo de busca por emprego, especialmente no que diz respeito a identificar ambientes de trabalho que sejam adequados às suas necessidades sensoriais, formas de comunicação e preferências. 

A plataforma oferece uma interface amigável e intuitiva para que os usuários possam responder a um questionário interativo de preferências, cadastrar informações de currículo e visualizar um painel de resultados com gráficos de compatibilidade profissional.

Este projeto foi construído focando em boas práticas de desenvolvimento, componentização e eficiência na comunicação com o backend.

## 🚀 Tecnologias Utilizadas

Abaixo estão as principais tecnologias e ferramentas empregadas na construção deste projeto:

**Frontend:**
* HTML, CSS e JavaScript
* React

**Backend / Banco de Dados:**
* TypeScript
* Lovable Cloud (como backend gerenciado com autenticação integrada)
* PostgreSQL

**Controle de Versão:**
* Git e GitHub
